Рекурсия зертханасы

Үлкен есепті кіші есепке айналдыр. Тоқтау шартын тап. Шақырулар тізбегін зертте.

20 тапсырма · Әр тапсырмаға 1 мүмкіндік

Ереже: әр тапсырмаға бір рет қана жауап бересің. «Тексеру» басылған соң жауап өзгермейді. Алдымен ойланып, содан кейін жібер. Бос жауап пен қате енгізу пішімі талпыныс ретінде есептелмейді.

Алдымен түсініп алайық

Функция өзін қалай шақырады?

Рекурсия — функцияның өзін тікелей немесе басқа функция арқылы шақыруы. Мұнда тікелей рекурсияны үйренеміз.

Практикум мақсаты: базалық жағдайды тану, кодты қадаммен талдау және рекурсивті функция жазу. Алдын ала білу: функция, if, return және бүтін сандармен амалдар.

01 · Тоқтайтын жерБазалық жағдай дайын жауапты қайтарады. Жаңа шақыру жасалмайды.
02 · Кішірейетін есепРекурсивті қадам аргументті базалық жағдайға жақындатады.
03 · Кері қайтуКүтіп тұрған шақырулар алынған мәндер арқылы аяқталады.
def fact(n):
    if n == 0:
        return 1
    return n * fact(n - 1)

print(fact(3))  # 6

Маңызды: return 1 экранға шығармайды. Ол ағымдағы шақырудан 1 мәнін қайтарады. print мәнді экранға шығарады. Бұл мысалда n — теріс емес бүтін сан, 0! = 1.

fact(3): шақырудан жауапқа дейін

Шақырулар стегі әр шақырудың қай жерге оралуы керектігін сақтайды. Базалық жағдайға жеткен соң есептеулер кері ретпен аяқталады.

Циклмен байланысы

1-ден n-ге дейінгі қосындыны циклмен де, рекурсиямен де табуға болады. Цикл әрекетті қайталайды; рекурсия жаңа функция шақыруын жасайды. Рекурсия әр есепте міндетті түрде тиімді бола бермейді.

total = 0
for i in range(1, n + 1):
    total += i
Оқу қорытындысы

Мен не үйрендім?

Әр дұрыс орындалған тапсырма — 1 балл. Жалпы балл = автоматты тексерілген 16 тапсырманың балы + барлық критерийі белгіленген 4 код тапсырмасының балы. Код тапсырмаларының балы оқушының өзін-өзі тексеруіне негізделеді. Бұл — жаттығу нәтижесі, мектеп бағасы емес.

Жіберілген жауаптар осы браузерде сақталады. Осы файлды сол браузерде немесе сол қойындыда жаңартқанда жауаптар қалпына келеді. Басқа оқушы үшін бөлек браузер профилін қолданыңыз. Жад қолжетімсіз болса, ескерту көрсетіледі. Код браузерде орындалмайды; еркін жауаптар үлгі және критерийлермен салыстырылады.
